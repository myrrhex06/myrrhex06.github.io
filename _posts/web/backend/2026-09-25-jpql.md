---

- `Entity` 객체를 대상으로 쿼리를 처리하는 객체 지향 쿼리임.
- SQL을 추상화하여 사용하기 때문에 특정 DB에 종속되지 않음.
    - 특정 DB에서만 제공되는 고급 기능은 사용 불가능함.
- `@Query` 어노테이션을 통해 `Repository` 인터페이스를 상속받은 인터페이스에서 직접 쿼리문을 작성할 수 있음

예시

```java
public interface ExampleRepository extends CrudRepository<ExampleEntity, Long> {

    @Query(value = "SELECT e FROM ExampleEntity e WHERE e.id = :id AND e.useYn= :useYn " +
            "ORDER BY e.createdDt DESC")
    Page<ExampleEntity> findExamplesWithPaging(Long id, String useYn, Pageable pageable);
}
```
