`FETCH`는 Oracle 12c 버전부터 사용 가능한 구문으로, 상위 N개의 데이터를 추출할 때 사용 가능함.

구문
```sql
SELECT 
  column_name
FROM table_name
ORDER BY column_name
[OFFSET n ROWS]
FETCH [FIRST/NEXT] n ROWS [ONLY/WITH TIES]
```

`FIRST`, `NEXT` 키워드의 경우 기능적으로는 둘이 동일함.

> `OFFSET`을 사용하지 않을 때는 `FIRST`, `OFFSET`을 사용할 때는 `NEXT`를 사용하면 의미를 좀 더 직관적으로 표현할 수 있음.

사용 예시 1

```sql
SELECT *
FROM EMP_SALES
ORDER BY SALES_AMT DESC
FETCH FIRST 3 ROWS ONLY;
```

`SALES_AMT` 컬럼 값을 내림차순 정렬 후 상위 3개의 데이터를 추출함.

결과

| -----: | -------- | --------- | ---------: | ---------- |
|      6 | 강현우   | 영업2팀   | 12,000,000 | 2019-11-03 |
|     12 | 임하늘   | 영업3팀   | 11,000,000 | 2021-02-28 |
|     13 | 조현준   | 영업3팀   | 11,000,000 | 2022-12-15 |

사용 예시 2

```sql
SELECT *
FROM EMP_SALES
ORDER BY SALES_AMT DESC
OFFSET 5 ROWS
FETCH NEXT 3 ROWS ONLY;
```

`SALES_AMT` 컬럼을 내림차순 정렬한 뒤 상위 5개의 행을 건너뛴 뒤 3개의 행을 추출함.
